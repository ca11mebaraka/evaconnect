# Лимиты

[English](rate-limits.md)

Серверного rate limit, заголовка квоты или HTTP 429 в захватах 2026-08-30 /
2026-09-02 не наблюдали.

Не выводите лимит из evaconnect:

- HTTP-кэш телеметрии в клиенте — **5 секунд** (`MIN_TELEMETRY_INTERVAL_S`).
  Это защита клиента, не задокументированное правило API.
- Опциональный poller по умолчанию: 30 с телеметрия / 900 с поездки. Та же оговорка.

Если измерите `Retry-After`, 429 или троттлинг WAF, запишите статус, заголовки
и эндпоинт в `openapi.yaml` как `partial`, пока не воспроизведёте дважды.
