# Ошибки

[English](errors.md)

На продакшене видели только эти HTTP-статусы. **Тела** ответов как стабильная
схема не захватывались; не предполагайте `{ "error": "..." }`.

| Status | Где | Смысл (как наблюдали) |
| --- | --- | --- |
| 400 | `POST /car-service/travels/search/{carId}` | Невалидные `sort.by` / `sort.dir` (`startDate` / `desc` отвергнуты) |
| 400 | `GET /config-service/config/flags` | Пустая query-строка (2026-09-02) |
| 401 | `POST /id-service/auth/refresh-token` | Refresh-токен отвергнут / уже ротирован |
| 401 | Авторизованный GET/POST | Access-токен отсутствует или истёк |
| 404 | `GET /charge-service/session/v2/current` | Нет текущей сессии зарядки (машина не заряжается) |

Не наблюдались (не документировать как поведение API): 403, 409, 422, 429, 5xx.

## 404 — не всегда «неизвестный маршрут»

**404** у charge `.../session/v2/current` — нормальное пустое состояние.
Считайте это «нет сессии», а не неверным путём.

## Восстановление после 401

Запрос данных 401 → `POST /id-service/auth/refresh-token` (без заголовка
`access-token`) → один повтор с новым access-токеном. 401 на самом refresh
значит повторный вход. Refresh **ротирует** `refreshToken`; повтор старого
refresh-токена даёт 401.
